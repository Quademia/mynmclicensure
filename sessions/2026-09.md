### Session mode (Sam asked; answer worth keeping)

Claude Code's "project" is the folder a session is opened in: that
folder's `CLAUDE.md` is auto-loaded, its memory directory is separate,
its history is separate. **One session per repo, opened in that repo's
folder.** Attaching another repo's folder to a session is right for
cross-repo discussion (today's morning) and wrong for building (today's
afternoon — the launcher symptom above). Codex has the same shape via
`AGENTS.md`. The memory Claude wrote today lives under the MyNclex
project and points here; a fresh licensure session starts from this
log, which is the design.
